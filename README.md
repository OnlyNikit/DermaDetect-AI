# 🧬 OncoGuardian AI Platform

> **Detect. Predict. Prevent.**

An AI-powered healthcare platform designed to assist in **early cancer detection**, **risk prediction**, and **continuous health monitoring**. The platform aims to help users identify potential health risks at an early stage and encourage timely medical consultation.

---

# 🚀 Features

### 🔍 AI-Based Cancer Detection

* Skin Cancer Detection using image analysis
* AI-powered prediction with confidence score
* Fast and user-friendly interface

### 📊 Risk Assessment

* Health questionnaire-based risk prediction
* Lifestyle and medical history analysis
* Personalized risk insights

### 📈 Health Monitoring Dashboard

* Health reports and prediction history
* Progress tracking
* Interactive analytics

### 🤖 AI Assistant

* Answers cancer-related questions
* Explains reports in simple language
* Provides preventive health guidance

### 🔐 Secure Authentication

* User Registration & Login
* Protected Dashboard
* Secure session management

# ⚙️ Installation

## Clone Repository

```bash
git clone git clone https://github.com/OnlyNikit/OncoGaurdian-AI-Platform.git
cd OncoGaurdian-Platform
```

## Frontend

```bash
cd Frontend
npm install
npm run dev
```

## Backend

```bash
cd Backend
npm install
npm run dev
```

## AI Services

```bash
cd AI-Services
pip install -r requirements.txt
python app.py
```
